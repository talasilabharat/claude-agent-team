## 4. Sync (automatic, no manual work)
- GitHub (github.com/talasilabharat, all repositories PRIVATE) is the MASTER copy. The sync (`workspace-control\scripts\sync-all.ps1`, started by the hooks) fetches GitHub, saves local changes after a secret scan, pulls newer work (rebase; if the same lines clash it undoes and reports, nothing lost), pushes, never forces. Newer GitHub work replaces older local files; newer local work goes up to GitHub.
- Never force-push. Never make a repository public. Never write a password, token or key into any file. A sync problem raises an ALERT: do not guess or overwrite; explain and ask.
- Version tags: every extension version is tagged on GitHub and GitLab.

## 9. Set up something new
- New project: `new-project.md` (this skill, choose NEW).
- New laptop (L3, ...): `bootstrap.md` does all of this by itself after one YES; in short: install Git (`winget install --id Git.Git -e --source winget --scope user`; ask first); sign in to GitHub once (the first clone opens a window; Bharat signs in); clone `workspace-control` into the workspace folder; run `scripts\setup-laptop.ps1 -Root <folder> -Label Lx` (confirm the label with Bharat; it registers the laptop and downloads every project); allow the GitLab http host and have Bharat save the GitLab token in Credential Manager; run `scripts\install-global-hooks.ps1` (you, permitted); then `start-check.ps1` must be clean.
- New Claude account: the only manual step (it must exist before this skill can) is in claude.ai: Customize > Plugins > Add > Add marketplace > `talasilabharat/claude-agent-team`, (leave the "Sync automatically" switch as it is; it does not deliver new versions by itself). After that "Start" does everything and keeps the plugin current by pressing "Check for updates" itself (`bootstrap.md`, `plugin-update.md`). The sign-ins and hooks belong to the Windows user, so another account on the same Windows user needs nothing more.

## 10. Words
- Repository = a project folder tracked by Git. Commit = a saved step. Push = send to GitHub. Pull = bring newer work down. Master copy = the one all others follow. Backup = a copy only.
